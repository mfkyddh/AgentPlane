# 📋 项目层

结论：项目层是四层文档体系的第二层，负责将战略转化为可执行的计划，管理进度、资源和风险。

---

## 四层文档体系

```
┌─────────────────────────────────────────────────────────────┐
│                    战略层 (Strategy)                         │
│         愿景 → 原则 → 路线图 → 决策记录                      │
├─────────────────────────────────────────────────────────────┤
│                    项目层 (Project) ← 当前层                 │
│         目标 → 范围 → 进度 → 资源 → 风险                     │
├─────────────────────────────────────────────────────────────┤
│                    工程层 (Engineering)                      │
│         流程 → 标准 → 工具 → 质量 → 协作                     │
├─────────────────────────────────────────────────────────────┤
│                    技术层 (Technical)                        │
│         架构 → 规范 → 实现 → 运维 → 验证                     │
└─────────────────────────────────────────────────────────────┘
```

## 与其他层的关系

### 向上：从战略层获取指导

- **愿景** → 指导项目目标
- **路线图** → 指导项目里程碑
- **原则** → 指导决策标准

### 向下：为工程层提供约束

- **项目目标** → 分解为工程任务
- **项目范围** → 约束工程实现
- **项目进度** → 驱动工程交付
