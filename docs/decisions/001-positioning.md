## 决策

AgentPlane 定位为"给 Agent 的产品全生命周期控制面"。

完整的定位声明、目标用户、非目标、成功标准、约束条件和决策理由，见 [愿景](../core/vision.md)。

## 替代方案

- **通用 Agent 框架**：范围太大，无法聚焦
- **大型 DevOps 平台**：目标用户不匹配，复杂度太高
- **SaaS 服务**：需要更多资源，不符合"可 fork"理念
