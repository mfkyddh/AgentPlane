# 010. 技术方向声明：务实主义、简洁优先、可替换 > 深耦合

## 背景

AgentPlane 是单人维护的项目，需要明确技术方向以指导日常决策。

## 决策

确立三项技术方向原则：

### 1. 务实主义

- 选择经过验证的方案，不追求技术新颖性
- 优先使用系统原生功能（SSH ControlMaster、bash、docker CLI）
- 不引入不必要的依赖

### 2. 简洁优先

- 代码量越少越好：3 个类能合并为 1 个就合并
- 文档越精简越好：砍掉不产生价值的元文档
- 测试覆盖关键路径，不追求 100% 覆盖率

### 3. 可替换 > 深耦合

- 外部工具（1Panel、Nginx UI）通过隔离层接入
- 核心逻辑不依赖特定第三方 API
- 接口稳定，实现可替换

## 理由

- 单人维护 = 复杂度是最大敌人
- 每引入一个依赖都是长期维护承诺
- 可替换性保证项目不会被单一工具绑架

## 替代方案

| 方案 | 为什么放弃 |
|------|-----------|
| 追求架构完整性 | 单人团队无法维护复杂的多层抽象 |
| 全面自建 | 开发和维护成本过高 |
| 深度集成单一工具栈 | 工具演进不可控，风险集中 |

## 影响

- 所有技术决策以此为基准
- 新增功能前先评估是否符合三项原则
- 文档和代码审查时以此为标准
