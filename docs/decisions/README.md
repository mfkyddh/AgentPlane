## 决策格式

每个决策记录包含：

1. **状态**：接受、拒绝、取代、实验
2. **日期**：决策日期
3. **背景**：为什么需要这个决策
4. **决策**：具体决策内容
5. **理由**：为什么选择这个方案
6. **替代方案**：考虑过的其他方案
7. **影响**：对产品、技术、文档的影响
8. **相关决策**：与其他决策的关联
9. **关联文档**：相关文档链接
