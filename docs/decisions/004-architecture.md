# 决策记录：架构演进

结论：采用 CLI-first、投影模型、可扩展三层架构。

---

## 状态

**接受**

## 日期

2026-04-30

## 背景

AgentPlane 需要明确核心架构决策，确保技术方向一致。

## 决策

### 1. CLI-first 架构

**决策**：所有正式操作通过统一 CLI 入口

**理由**：
- Agent 友好：AI 可以直接调用 CLI
- 人类友好：命令行界面简洁直观
- 可审计：所有操作有记录
- 可扩展：新功能通过新命令添加

**替代方案**：
- API-first：需要额外的客户端，复杂度高
- GUI-first：不利于 Agent 调用

### 2. 三层投影模型

**决策**：数据分为三层，各司其职

| 层 | 类比 | 用途 |
|---|---|---|
| Inventory（台账） | 货物清单 | 声明性数据，人类可读 |
| Ledger（证据） | 盘点记录 | 机器派生数据，不可篡改 |
| Summary（摘要） | 月度报告 | 人类可读结论 |

**理由**：
- 分离关注点：声明、证据、结论各司其职
- 可追溯：从结论可追溯到证据
- 可审计：证据不可篡改

### 3. Skill 路由

**决策**：AI Agent 通过 Skill 调用能力，Skill 路由到 CLI

**理由**：
- Agent 友好：AI 看到的是能力，不是命令
- 人类友好：CLI 命令简洁直观
- 可扩展：新能力通过新 Skill 添加
- 可审计：所有调用有记录

### 4. 执行闭环

**决策**：所有操作遵循 Plan → Apply → Verify → Record 流程

**理由**：
- 安全：执行前有计划
- 可靠：执行后有验证
- 可追溯：所有操作有记录
- 可回滚：记录支持回滚

### 5. 安全护栏

**决策**：AI 必须遵守的规则

**理由**：
- 安全：防止 AI 误操作
- 可控：人类掌控关键决策
- 可审计：所有操作有记录

### 6. 人类在环

**决策**：关键决策需要人类确认

**理由**：
- 安全：防止 AI 误操作
- 可控：人类掌控关键决策
- 可审计：所有操作有记录

## 理由

### 为什么选择这些架构决策？

1. **Agent 友好**：所有决策都考虑了 AI 的使用场景
2. **人类友好**：所有决策都考虑了人类的使用场景
3. **可扩展**：所有决策都支持未来扩展
4. **可审计**：所有决策都支持操作追溯

## 替代方案

### 方案 A：API-first 架构

**描述**：所有操作通过 API 进入

**优点**：
- 标准化
- 可扩展

**缺点**：
- 需要额外的客户端
- Agent 调用不如 CLI 直接
- 人类使用不如 CLI 直观

### 方案 B：GUI-first 架构

**描述**：所有操作通过 GUI 进入

**优点**：
- 用户体验好
- 可视化

**缺点**：
- 不利于 Agent 调用
- 开发成本高
- 维护成本高
