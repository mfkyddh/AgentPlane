# History Index

结论：`docs/history/` 只做历史说明，不重新长出第二套正文；旧阶段计划、设计稿和交接记录已从开源 active tree 移除，历史内容以 Git history 为准。

## Stage Plans

- 阶段计划不再作为 active docs 发布，避免旧路径和迁移期入口回流。

## Design Specs

- 历史设计稿只通过 Git history 查询；active contract 以 `docs/architecture/` 和 `docs/reference/` 为准。

## Handoffs

- 会话交接不进入开源文档面；跨阶段约束必须沉淀到 active runbook、测试或代码合同。

## Boundary

- `docs/history/` 只说明历史资料边界，不复制历史正文。
- 一次性窗口步骤和退出主流程的专题不放这里，应进入 `docs/archive/`。
- 当前 active 读者入口仍以仓库根 `README.md`、`docs/architecture/README.md` 和 `docs/runbooks/` 为准。
