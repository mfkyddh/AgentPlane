# 🌟 AgentPlane 愿景

结论：AgentPlane 的愿景是成为"给 Agent 的产品全生命周期控制面"，帮助个人开发者、小团队、开源维护者和自托管服务维护者安全地管理产品从创建到运维的全过程。

---

## 一句话愿景

**给 Agent 的产品全生命周期控制面**

**含义**：
- **Agent**：AI 代理，直接用英文
- **产品**：包含多个业务系统 + 全局配置
- **全生命周期**：从创建到运维的所有阶段
- **控制面**：决策层，不是执行层

---

## 长期目标

**3 年内成为小团队的标准工具，拥有 100+ 用户**

**衡量标准**：
- 用户数：100+
- 时间：3 年
- 范围：小团队

---

## 核心价值主张

**Agent 安全管理产品全生命周期**

**含义**：
- **Agent**：AI 代理，直接用英文
- **安全**：安全可控，不是无限制
- **管理**：决策层，不是执行层
- **产品全生命周期**：从创建到运维

---

## 目标用户

| 用户类型 | 特点 | 需求 |
|----------|------|------|
| **个人开发者** | 独立工作，资源有限 | 简单、自动化 |
| **小团队（2-10 人）** | 协作工作，资源有限 | 标准化、可追溯 |
| **开源维护者** | 维护开源项目，资源有限 | 统一、可审计 |
| **自托管服务维护者** | 维护自己的服务，资源有限 | 安全、可控 |

**共同特点**：
- 资源有限
- 需要自动化
- 需要安全可控
- 需要可追溯

---

## 成功标准

**用户满意度**

**含义**：
- 不依赖外部指标（用户数、活跃度、影响力）
- 依赖内在感受（功能实现、用户体验、项目质量）
- 主观判断，而非客观数据

**衡量方式**：
- 你自己对项目功能实现的满意度
- 用户对项目体验的满意度
- 项目本身的质量和完整性

## 非目标

### 不替代现有工具

| 工具 | 非目标 | 理由 |
|------|--------|------|
| **Terraform** | 不管云资源全生命周期 | 范围太大，不是 AgentPlane 的定位 |
| **Kubernetes** | 不做容器编排 | 复杂度太高，不是 AgentPlane 的目标 |
| **Ansible** | 不做配置编排 | 偏 Agent 任务入口和证据，不偏配置执行 |
| **CI/CD 工具** | 不做持续集成/持续部署 | 专注于产品生命周期管理 |
| **监控工具** | 不做实时监控 | 专注于运维管理，不专注于实时监控 |

### 不服务的场景

| 场景 | 非目标 | 理由 |
|------|--------|------|
| **大型企业** | 不支持大型多租户平台 | 目标用户是小团队和个人开发者 |
| **强一致场景** | 不支持强一致持续调谐 | 不是常驻 reconciler |
| **实时系统** | 不支持实时系统 | 专注于产品生命周期管理 |

### 不成为的形态

| 形态 | 非目标 | 理由 |
|------|--------|------|
| **SaaS** | 不做托管服务 | 当前阶段不适合，需要专注核心功能 |
| **通用 Agent 框架** | 不做通用 Agent 框架 | 专注于产品生命周期管理 |
| **大型 DevOps 平台** | 不做大型 DevOps 平台 | 目标用户是小团队和个人开发者 |

### 不管的内容

| 内容 | 非目标 | 理由 |
|------|--------|------|
| **业务开发** | 不管代码编写、代码审查、单元测试 | 这些是人类的工作 |
| **代码编辑** | 不做代码编辑器 | 留给专业工具 |
| **版本控制** | 不做版本控制系统 | 留给 Git 等工具 |

## 项目定义

### 项目层级

```
项目（Project）
├── 业务系统（Business System）
│   ├── 应用（Application）
│   └── ...
├── 业务系统（Business System）
│   ├── 应用（Application）
│   └── ...
└── 全局配置（Global Config）
```

### 配置管理

- **声明方式**：应用通过配置文件（如 `config.yaml`）声明配置
- **管理方式**：Agent 负责配置的存储、同步、验证

### 操作粒度

| 操作类型 | 负责方 | 包含的操作 |
|----------|--------|------------|
| **业务开发** | 人类 | 需求分析、架构设计、代码实现、代码审查、单元测试 |
| **运维相关** | AgentPlane | 构建、部署、监控、运维、故障排查 |
