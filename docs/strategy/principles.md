# 哲学与工程原则

结论：AgentPlane 的原则分三层——哲学基座约束思维方式，方法论约束工作方式，工程原则约束代码。优先级：工程原则 > 方法论 > 哲学基座。

---

## 三层架构

```
┌─────────────────────────────────────────┐
│           工程原则                        │
│   YAGNI / DRY / KISS / SOLID            │
│   CLI-first / 投影模型 / 执行闭环       │
├─────────────────────────────────────────┤
│           方法论                        │
│   调查研究 / 群众路线 / 批评与自我批评   │
├─────────────────────────────────────────┤
│           哲学基座                        │
│   实事求是 / 矛盾分析法 / 第一性原理     │
└─────────────────────────────────────────┘
```

---

## 工程原则

| 原则 | 核心要义 |
|------|----------|
| **CLI-first** | 所有操作通过 `agentplane ...` 统一入口 |
| **投影模型** | Host Inventory → Object Ledgers → App Summaries |
| **执行闭环** | Plan → Apply → Verify → Record |
| **YAGNI** | 不要过度设计 |
| **DRY** | 消除重复代码 |
| **KISS** | 保持简单 |

---

## 方法论

| 原则 | 核心要义 |
|------|----------|
| **调查研究** | 先调查再发言 |
| **群众路线** | 收集 → 系统化 → 返回 → 验证 |
| **批评与自我批评** | 惩前毖后，治病救人 |

---

## 哲学基座

| 原则 | 核心要义 |
|------|----------|
| **实事求是** | 从客观存在的实际事物出发 |
| **矛盾分析法** | 识别并抓住主要矛盾 |
| **第一性原理** | 从最基本的事实出发，而不是类比 |
| **奥卡姆剃刀** | 如无必要，勿增实体 |
