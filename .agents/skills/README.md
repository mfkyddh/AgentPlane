# OP_Linux repo-level skills

This directory is the repo-scoped entrypoint for OP_Linux skills.

- Runtime source of truth for the skill content stays in `/root/work/OP_Linux/.codex/skills`.
- Projection source of truth for this layer stays in `/root/work/OP_Linux/.codex/skills/catalog.yaml`.
- Entries in this directory are generated lightweight pointers to the corresponding repo-owned skills.
- Global `~/.agents/skills` is reserved for cross-repository personal skills.
